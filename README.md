# Week 3 - Sales Data Analysis

## Project Overview

This project analyzes a sales dataset using Python and Pandas.

The objective is to explore the dataset, check data quality, calculate important sales metrics, identify the best-selling product, and create a clean formatted report.

## Technologies Used

- Python
- Pandas
- CSV
- IDLE

## Dataset

The dataset contains 100 rows and 7 columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales

## Analysis Performed

The project performs:

1. Loading the CSV dataset using Pandas
2. Exploring the first few rows
3. Checking dataset shape and columns
4. Checking data types
5. Checking missing values
6. Checking duplicate rows
7. Calculating total sales
8. Calculating average sales
9. Finding highest and lowest sales
10. Finding the best-selling product
